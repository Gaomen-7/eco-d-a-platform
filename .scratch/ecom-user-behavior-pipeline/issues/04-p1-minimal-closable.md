## Question

目的地是「spec-ready 路线图」，而路线图第一段是 P1。现状是：`SRS §7` 把 P1 定义为一长串需求的集合（`REQ-F-GEN-*`、`REQ-F-MQ-*`、`REQ-F-RT-01..08`、`REQ-F-OLAP-01..03`、`REQ-F-BI-01..04`、`REQ-F-VERIFY-01/02`），**没有一条说「P1 做到这里就算成立，剩下的留给 P2/P3」**。于是「P1 完成」这个状态目前无法判定：

- 迟到修正（`REQ-F-RT-04`）、DLQ 分类（`REQ-F-RT-07`）、`verify-fault`（`REQ-F-VERIFY-03`，SHOULD）——它们是 P1 的一部分，还是「P1 尾巴」？
- 脏率面板（`REQ-F-BI-04`，SHOULD）与「暂定/落定视觉区分」（gdd §1.6，`【已确认 Q13】`）——哪一个是 P1 成立的硬条件？
- 冷启动 ≤15 min（`REQ-NF-CAP-03`）与 ≤8 GB（`REQ-NF-CAP-01`）——是 P1 的**门槛**，还是 P1 之后的**记账**？
- `gdd §1.3` 新增的「行为可证」判据（`revision > 0` 出现、脏率不上升、漏斗单调、UV 与离线逐窗口相等）——四条里有几条是 P1 必须证明的？

这台票要你把 P1 切成三圈：

| 圈 | 含义 | 读法 |
| --- | --- | --- |
| **PI-1 最小闭环** | 不成立则 P1 不成立 | 每一条给一个**可执行断言**（退出码 / 标量 / 字段） |
| **PI-2 加固** | 成立则 P1 更好，但不阻塞进入 P2 | 允许延后，须写明延到哪一段 |
| **PI-3 标注** | 只要求在文档里标注风险/口径，不要求实现 | 例如 Experimental 的 early-fire |

并回答：**「P1 成立」的判定动作是什么**——一次 `make verify` + 一次人工看板观察（GIF）？还是三条独立的机器断言？谁签字。

## Answer

**Resolved 2026-10-20（本会话，map 落子时一并裁决；用户可推翻）。** 详细推理与四条「为什么是它」写在 [map.md](../map.md) 的「为什么建议第一个目标是它」与 Decisions so far 的 D4 条目；此处只留票级结论。

**裁决：本票不再问「P1 做什么」，只问「P1 怎样算成立」。** 理由三条，逐条有据：

1. **目的地已经把它收窄了**。`map.md` 的 Destination 是「一份 spec-ready 路线图」，不是「一个能跑的 P1」。P1 的实现属于路线图的下游（施工），不属于路线图本身（决策）。
2. **仓库里没有任何一份文档定义「P1 完成」这个状态**。SRS §7 给的是需求集合，FSR §9 给的是里程碑名 + 一句判据（「看板持续刷新；`make verify` 通过；`verify-fault` 通过」），gdd §1.3/§1.8 给了判据的**零件**。零件 ≠ 判定动作。
3. **它卡住最多下游**（[03]/[05]/[09]/[07]/[02] + 迷雾 F1/F2/F3/F6/F9），且是 HITL——答案只有你能给（「我的作品要证到什么程度」），agent 代答就是又一次「按推荐」。

**已回填的连带裁决**（这三条同时改写了本图的构成，逐条可见于地图 Decisions so far 的 D4）：

- 本图目的地的**验证标准**是「解到 frontier 为空时，路线图是唯一还站着的规划文档」；「spec-ready」不被当作「施工规格已完成」。
- **冻结面不进图**：C3 锚点、八个 Makefile 目标名、四个端口、`ecom_ads`/`ecom_lake` 库名一律不当目标；要改走冻结项变更。
- **设计面就地落子、不进票**：冷启动两档与 8 GB 天花板的记账、三份 P0 交接的合并、现状 → 目的地 DAG 本身，都由 D4 直接给出（或已在 HLD §7.3 给出），不再单独开票——否则「路线图」的第一步会变成「解一堆只有一两行结论的琐事」。

**未被本票吸收的口子（保留，不要当成已决）**：

- `REQ-F-LAKE-08` 的验收判据冲突（SRS「受控为 5」 vs gdd D7「5 是下限」）**仍无票拥有**；[07] 只做成本侧调研，[01] 只做规范侧调研（见 map-dag 缺口 #1、#2 的说明已改写为「缺口保留」）。
- P1 圈表的**具体切法**仍要你裁决——那正是本票留白的原因。

**下游影响**：迷雾 F3（live 确定性）、F6（Superset delivery）、F9（降级触发）仍挂在 [04] 名下，等 P1 圈表定下来再决定毕业与否。

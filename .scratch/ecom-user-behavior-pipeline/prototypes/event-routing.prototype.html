原型 · 事件处置：一条事件到底落在哪

一次性原型，只回答一个问题，答完即弃。

被问的问题：一条事件可能同时违规（脏）、迟到、重复——判定顺序决定它最终落在主指标、修正通道、迟到计数、重复计数，还是 DLQ；而这四个落点的下游对账口径完全不同。
在纸上说不清的是：重复到底算不算脏、故障恢复重放会不会污染「脏数据率」、既脏又迟到时谁优先。下面可以按按钮，把状态推过去看。

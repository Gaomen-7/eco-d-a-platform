# 为什么需要这个文件（P0 实测）：
#   apache/superset:6.1.0 官方镜像**不含任何数据库驱动** —— psycopg2 / psycopg /

#   Doris 前端走 MySQL 协议 ⇒ 必须提供一个 MySQL 驱动。
#
# 选 PyMySQL 而非 mysqlclient：纯 Python，不需要编译 mysql 客户端库，
# 在 127.0.0.1 单机场景够用，且安装失败面小。
